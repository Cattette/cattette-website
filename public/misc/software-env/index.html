My Software Environment

The normal environment most of us are expected to navigate our lives through is completely unusable. Everything wants to be a pop-up, everything wants to fingerprint you, everything wants to track you, and they all want to do it on your CPU.

Im no software engineer but I know enough about computer files to recognize that doing simple tasks with a 4.0 KiB text file or searching for a file in a small directory probably shouldn’t make your entire computer buffer for half a second.

Perhaps I’m just especially sensetive to latency, but I know I’m not alone. Fortunately, in the software enthusiast space people actually seem to maintain a modicum of respect for your time and resources.

Here’s a list of the software I use daily and some notes to go along with them:

  • Arch Linux, Cachy OS is a phenomenal alternative (mainly because it’s also Arch), with an alternate kernel and a simpler installation experience.
  • The Sway tilling window manager
  • Helix, a very nifty modal text editor inspired by Vi. It is similar to Neovim with a few sane plugins a alternate (saner) set of motions.
  • The Foot terminal emulator. It strikes a pleasant balance between emulators like st and Alacritty.
  • The Rofi dmenu replacement.
  • Qutebrowser, my principal browser. It is based on QtWebEngine (which is based on Chromium). I also use a normal Firefox build as a rarely needed back-up.
  • GIMP, the only serious FOSS general image manipulation program. The annoying user experience is easily forgiven given its technical capabilities. Any image manipulation software which allows you to edit and preserve 16- 32-bit bitmaps, color channels, and transparency gets a gold star in my book.
  • QGIS The GIMP of geographic information system (GIS) software. While most would argue that GIMP is a inferior product to its main commercial competitor Photoshop, I have never met anyone who prefers any of the commercial GIS software over QGIS.
